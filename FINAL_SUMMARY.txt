🚀 КАК ЗАПУСТИТЬ:
================================================================================

1. Откройте .env и добавьте ваш API ключ:
   
   LLM_PROVIDER=openai
   OPENAI_API_KEY=sk-your-key-here

2. Запустите Docker:
   
   docker-compose up --build

3. Откройте браузер:
   
   http://localhost:5173      - Приложение
   http://localhost:8000/docs - API документация

4. Зарегистрируйтесь и начните практиковать английский!
