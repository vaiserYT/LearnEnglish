## 🚀 Как запустить

### 1. Откройте .env и добавьте API ключ:
```bash
LLM_PROVIDER=openai
OPENAI_API_KEY=your-key-here
```

### 2. Запустите:
```bash
docker-compose up --build
```

### 3. Откройте браузер:
- http://localhost:5173 - приложение
- http://localhost:8000/docs - API документация

## 🎯 Основные функции

### 1. Регистрация и аутентификация
- JWT токены с 7-дневным сроком действия
- Безопасное хранение паролей (bcrypt)
- Автоматическое сохранение сессии

### 2. Оценка уровня
- AI анализирует ответы пользователя
- Определяет уровень (beginner → advanced)
- Создает персонализированный план обучения

### 3. Разговорная практика
- AI адаптируется под уровень студента
- Генерирует контекстные ответы
- Исправляет ошибки с объяснениями
- Отслеживает типичные ошибки

### 4. Адаптивное обучение
- План обновляется после каждой сессии
- Выявляет слабые и сильные стороны
- Подбирает следующие темы для практики
- Фокусируется на проблемных областях

### 5. Прогресс и аналитика
- Общее время практики
- Количество разговоров и сообщений
- Оценки по 4 навыкам (fluency, pronunciation, grammar, comprehension)
- Streak дней для мотивации
- История всех разговоров

## 🔧 Технические детали

### Архитектура
- **Backend**: Трехслойная архитектура (Router → Service → Database)
- **Frontend**: Компонентная архитектура с разделением concerns
- **Database**: Нормализованная схема с внешними ключами
- **LLM**: Унифицированный интерфейс для разных провайдеров

### Безопасность
- JWT аутентификация
- Bcrypt хеширование паролей
- CORS защита
- SQL Injection защита (ORM)
- Валидация входных данных (Pydantic)
- API ключи только в .env

### Масштабируемость
- Docker для изоляции и развертывания
- Асинхронный FastAPI для производительности
- Подготовлено для добавления Redis кеширования
- Возможность добавления Celery для фоновых задач
